# 🧁 Baking with Ria

Welcome to **Baking with Ria**, a bright, colorful, baking-themed website built using HTML, CSS, and JavaScript!

## 🌐 Live Website Link
👉 **[View the Live Website Here](https://riasheth09-cell.github.io/Baking-with-Ria/)**

---

## 📋 Project Overview
This website showcases fresh, colorful home-baked treats and interactive recipes. It is designed with a consistent color scheme, unified navigation, and Times New Roman typography across all pages.

### 📄 Pages Included
1. **Home (`index.html`):** Welcome banner, interactive cookie clicker game, and baked goods gallery.
2. **Cupcakes (`cupcakes.html`):** Funfetti Cupcake recipe with a dynamic ingredient calculator.
3. **Cookies (`cookies.html`):** Golden Chocolate Chip Cookie recipe with an interactive baker's tip toggle.

---

## ⚡ Interactive Features (JavaScript)
- 🍪 **Interactive Cookie Counter:** Collect virtual cookies on the home page with milestone alert pop-ups.
- 🎨 **Color Theme Switcher:** Toggle between two vibrant color themes on any page via the footer button.
- 🔢 **Dynamic Ingredient Yield Calculator:** Adjust portion sizes on the cupcake page to automatically recalculate ingredient quantities.
- 💡 **Show/Hide Secret Tip:** Reveal or hide baking tips on the cookie recipe page.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic structure, headings, links, images, ordered & unordered lists.
- **CSS3:** Custom page layout, responsive design grids, and Times New Roman font styling.
- **JavaScript:** Interactive DOM manipulation, event listeners, and math functions.
